# نبض تابلو

نسخه توسعه محلی تابلوخوانی با Node.js 24، Express، MongoDB، TypeScript و رابط React/Vinext.
**تنها منبع داده بازار، دامنه مستقیم TSETMC است. هیچ داده نمایشی ساختگی در سایت تزریق نمی‌شود.**

## اجرا در ویندوز

پیش‌نیاز: Node.js نسخه ۲۴ یا جدیدتر، MongoDB در حال اجرا، دسترسی اینترنت به `cdn.tsetmc.com`.

```powershell
cd C:\Users\asus\Documents\ChatGPT\tablokhani
npm.cmd run setup
Copy-Item .env.example .env
npm.cmd run dev
```

اگر `.env` را قبلاً تنظیم کرده‌اید، آن را بازنویسی نکنید. در این دستگاه وابستگی‌ها نصب شده‌اند؛ برای اجرای بعدی معمولاً فقط `npm.cmd run dev` لازم است.

نشانی سایت: **http://127.0.0.1:3000**

سلامت API: **http://127.0.0.1:4000/api/health**

با `Ctrl+C` سرویس‌های همین اجرا متوقف می‌شوند. `npm run dev` چهار پردازش رابط، API، دریافت‌کننده و worker را اجرا می‌کند. دریافت‌کننده هنگام شروع یک بار منبع را می‌خواند و سپس فقط در بازه بازار تنظیم‌شده نمونه‌برداری می‌کند. برای دریافت دستی در هر ساعت:

```powershell
npm.cmd run collect:once
```

worker باید در حال اجرا باشد تا دریافت جدید پردازش شود. MongoDB پیش‌فرض: `mongodb://127.0.0.1:27017`، نام دیتابیس: `tablokhani_dev`. هیچ دیتابیس موجود دیگری دستکاری نمی‌شود.

## امکانات قابل استفاده

- خلاصه بازار، جدول نمادها، مرتب‌سازی، جست‌وجوی فارسی، فیلتر صنعت/قدرت خرید/جریان پول و صفحه‌بندی.
- نقشه رنگی، مقایسه صنایع، صفحه نماد و آمار حقیقی‌حقوقی.
- دیده‌بان شخصی ذخیره‌شده در MongoDB، خروجی CSV سازگار با Excel، پوسته روشن/تیره.
- ذخیره هشدار قدرت خریدار؛ اعلان داخلی حداکثر یک بار در روز برای هر قانون.
- ثبت نمونه‌های زمانی، نمودار روند و کندل روزانه تعدیل‌نشده مستقیم TSETMC (دریافت با دکمه در تب تاریخچه نماد).
- رویدادهای برآوردی پول داغ/پلاس، تجمیع ده‌دقیقه‌ای، رصد بازار و نمودار چندبعدی.
- انتشار آخرین وضعیت با SSE، علامت‌گذاری قطع ارتباط و داده کهنه.

## محدودیت‌های روشن این نسخه

این نسخه، پایه قابل اجرای پروژه است؛ هنوز برابری کامل با تمام امکانات سایت مرجع ندارد.

- فرمول‌های اختصاصی کستیک، D⁺، M⁺، عدد طلایی، امتیاز تابلو، ریسک و حمایت/مقاومت بازسازی نشده‌اند. صفحه کستیک این موضوع را صریحاً می‌گوید؛ مقادیر حدسی تولید نمی‌شود.
- بازی بازار فعلاً مقایسه سرانه‌هاست؛ تفکیک هویت یا اندازه واقعی معامله‌گران از داده تجمیعی قابل اثبات نیست.
- نمودار داخل روز از نمونه‌های جمع‌آوری‌شده است و تاریخچه کامل معاملات محسوب نمی‌شود. نمونه شروع کار فقط یک نقطه می‌دهد.
- تاریخچه روزانه از منبع اصلی دریافت می‌شود، تعدیل قیمت/افزایش سرمایه هنوز پیاده نشده است.
- پاسخ دیده‌بان ممکن است سفارش‌ها را با صفر برگرداند؛ در این حالت «سفارش معتبر موجود نیست» نشان داده می‌شود، نه صف خرید/فروش فرضی.
- در پاسخ bulk مشاهده‌شده، تاریخ معامله `dEven` صفر بوده است. روز پارتیشن‌بندی فعلاً **روز دریافت تهران** است، نه تاریخ معامله تأییدشده. زمان دریافت با زمان آخرین معامله یکسان نیست. برای تاریخ روزانه، تاریخ صریح منبع موجود است.
- تعطیلات، زمان‌بندی جداگانه ابزارها و قرارداد داده باید در طول روز بازار نیز اعتبارسنجی شوند. تنظیم روزهای تعطیل از `MARKET_CLOSED_DATES` ممکن است.
- تک‌کاربره و محدود به loopback است؛ ورود پیامکی، تفکیک حساب‌ها، احراز هویت تولید، اشتراک و انتشار عمومی آماده نشده‌اند.
- صف پایدار فعلاً در MongoDB است. Redis در این نسخه نصب/الزامی نیست؛ قبل از مقیاس چندسروری، قفل دارای fencing، صف و کش توزیع‌شده لازم است.
- گرفتن CSV جای فایل بومی XLSX است. پنل آموزش، کدال، سهامداران و تالار معاملات در این نسخه نیستند.
- بررسی وابستگی‌های رابط پس از ارتقا هنوز ۷ هشدار انتقالی (۳ بالا و ۴ متوسط) در زنجیره ابزارهای تصویر/OG و شبیه‌ساز استقرار نشان می‌دهد؛ این نسخه برای انتشار عمومی تأیید نشده است. رفع این زنجیره باید قبل از استقرار تولید کامل شود.

## بررسی‌ها

```powershell
npm.cmd test
npm.cmd run test:integration
npm.cmd run typecheck
npm.cmd run typecheck:web
npm.cmd run build
```

تست integration یک دیتابیس موقت با پیشوند `tablokhani_test_` می‌سازد و فقط همان دیتابیس را در پایان حذف می‌کند. فایل‌های آزمون داده مصنوعی دارند؛ این داده‌ها وارد دیتابیس اصلی یا رابط نمی‌شوند.

`npm start` فقط API را اجرا می‌کند. برای کار محلی از `npm run dev` استفاده کنید. خروجی build رابط با سرویس Express/MongoDB، استقرار کامل تولید محسوب نمی‌شود.

## رفع اشکال

- MongoDB قطع است: با `Get-Service MongoDB` وضعیت سرویس را ببینید و در صورت نیاز آن را از Services ویندوز اجرا کنید.
- `EADDRINUSE`: یک اجرای قبلی را با `Ctrl+C` ببندید. API روی ۴۰۰۰ و رابط روی ۳۰۰۰ اجرا می‌شوند.
- پیام مسدودی TSETMC: داده قبلی حفظ می‌شود. هیچ منبع جایگزین، دورزدن محدودیت یا عدد تصادفی به‌کار نمی‌رود.
- نمودار خالی: در دریافت اول طبیعی است؛ برای کندل روزانه دکمه «دریافت تاریخچه مستقیم» را بزنید.
- خطای اجرای `npm.ps1`: از `npm.cmd` استفاده کنید؛ نیازی به تغییر سیاست اجرای PowerShell نیست.
